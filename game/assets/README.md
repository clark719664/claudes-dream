# Art pack goes here

This game uses the **Pixel Crawler — Free Pack** by Anokolisa:
https://anokolisa.itch.io/free-pixel-art-asset-pack-topdown-tileset-rpg-16x16-sprites

Its terms allow commercial use but not redistributing the files, so the pack is not committed.
Download it and unzip it into this folder so that this path exists:

    game/assets/Pixel Crawler - Free Pack/Environment/Tilesets/Floors_Tiles.png

Then open `game/project.godot` in Godot 4.4 (it imports the pack on first open).
