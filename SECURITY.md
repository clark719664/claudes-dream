# Security policy

Cron Almanac is a static page. It has no server, no accounts and no stored data beyond your own browser's local storage. The most likely kind of vulnerability is a crafted link or pasted text that makes the page run script (cross-site scripting).

## Reporting a vulnerability

Please report it privately. Don't open a public issue.

Use **Report a vulnerability** on the repository's [Security tab](../../security/advisories/new). You'll get a reply within a week. Once it's fixed, you'll be credited in the release notes unless you'd rather not be.

## Supported versions

Only the latest version on `main` is supported.
